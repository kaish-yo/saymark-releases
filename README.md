# Saymark

会議の音声を文字に起こし、要約を作るWindowsアプリです。

## 使い方

1. [ダウンロードページ](https://github.com/kaish-yo/saymark-releases/releases)からアプリをダウンロードし、ZIPを展開します。
2. `Saymark.exe`を起動し、「API設定」でOpenAIのAPIキーを登録します。
3. 「新しい会議」から録音を始めます。

## 必要なもの

- Windows 10 / 11（64ビット）
- インターネット接続とOpenAIのAPIキー（API利用料がかかります）

文字起こしのために音声を、要約のために文字起こしの内容をAPIへ送信します。
